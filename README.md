# Ask X

在 X 上划词，一键问右下角的 Grok 小窗。X Grok 划词（Grok-quote）的净室重写，**一切皆插件**：结构照 void++（definePlugin / definePluginSettings / OptionType、必需插件、收藏和置顶、插件页 + 插件设置弹窗），每个功能都是一个可单独开关、单独设置的插件。

## 安装

```sh
npm run build        # 或在 Chat-blocker 根目录 npm run build:askx
```

把 `dist/Ask X.user.js` 导入暴力猴 / Tampermonkey。旧的 X Grok 划词请先停用。

## 插件

| 插件 | 默认 | 作用 | 设置 |
| --- | --- | --- | --- |
| AskGrok | 必需 | 划词工具条 + 引号按钮，把引文写进 Grok 小窗；其他插件都挂在它上面 | — |
| NewChat | 开 | 提问前先点 Grok 的 New Chat；输入框里没发的草稿会带到新对话 | — |
| Incognito | 开 | 工具条上的幽灵按钮走 Private Chat；普通提问时先关掉残留的无痕 | — |
| QuoteFormat | 开 | 自定义引用模板（`{text}` `{quote}` `{url}` `{author}`）；关闭时用默认格式 | 引用模板 |
| QuickPrompts | 开 | 工具条上的“解释”“翻译”等一键提问，按钮显示“图标 + 名字” | 按钮列表（图标 URL、名字、模板、无痕、自动发送）。图标填 https 图片地址或 data:image URL，留空不显示；X 的安全策略不允许直接加载外站图片，https 图标由脚本管理器下载后转成 data URL 并缓存 |
| UserQuotes | 开 | 移植自 void++：你发给 Grok 的消息里以 > 开头的行显示为带左侧竖线的引用块（Grok 小窗和 Grok 全页） | 斜体、引号 |
| Toasts | 开 | 底部结果提示（旧脚本已有） | — |
| MenuCommands | 开 | 脚本菜单里的“问 Grok / 无痕问 Grok（当前划词）” | — |
| NoSuggestions | 开 | 隐藏 Grok 输入框（小窗和 Grok 全页）下面那排功能提示按钮（Create Videos / Create Images / Edit Image / Latest News）；按结构识别，不依赖界面语言，不影响输入框按钮和 Private Chat 说明 | — |
| Settings | 必需 | 设置界面（脚本菜单“Ask X 设置”） | — |

设置界面：左侧导航（插件 / 关于），插件页有分类标签（收藏、全部、输入框、对话、隐私、通知、导航、精简、开发）、搜索框、启用状态筛选、两列插件卡片（星标收藏、置顶、调节图标打开设置、开关），必需插件排在分隔线后并变灰。默认打开“收藏”，没有收藏时打开“全部”（void++ 固定打开收藏，这里为避免第一次打开是空页面）。旧版（v1.0）的设置会自动迁移到对应插件。

## 开发

```sh
npm test       # 36 个 jsdom 单元测试
npm run verify # 构建 + 元数据校验 + 测试
```

| 目录 | 职责 |
| --- | --- |
| `src/api/plugins.js` | 插件框架：definePlugin、definePluginSettings、OptionType、插件管理（启停、必需、收藏、置顶、存储） |
| `src/api/events.js` / `migrate.js` | 插件间事件、v1 设置迁移 |
| `src/plugins/` | 10 个插件，`index.js` 决定注册顺序 |
| `src/ui/` | 设置窗口、插件设置弹窗、开关/下拉/滑块等控件 |
| `src/drawer.js` | 打开小窗、New Chat、Private Chat、写入、发送 |
| `src/toolbar.js` | 划词工具条（按钮来自已启用的插件） |
| `src/text.js` / `source.js` / `x-strings.js` | 规范化和模板、推文来源、X 多语言按钮文案 |
